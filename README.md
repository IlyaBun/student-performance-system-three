# ИАС ПолесГУ - Система оценки успеваемости студентов

Программная система оценки количественных и качественных показателей успеваемости студентов инженерного факультета ПолесГУ.

## 📋 Описание

Клиент-серверная система с графическим интерфейсом для управления успеваемостью студентов. Поддерживает три роли пользователей: администратор, преподаватель и студент.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск системы

```bash
python main.py
```

При первом запуске система автоматически создаст базу данных и заполнит её демонстрационными данными.

## 👥 Учётные данные

### Администратор
- **Логин:** `admin`
- **Пароль:** `RwQNt`

### Преподаватели
- **Логин:** `teacher1`, `teacher2`, `teacher3`

### Студенты
- **Логин:** `student1` ... `student250`
- **Пароль:** `password`

## 🎯 Возможности

### Роль Admin
- Полный доступ ко всем функциям системы
- Управление пользователями (повышение студентов до преподавателей)
- Просмотр логов действий
- Доступ ко всем вкладкам

### Роль Teacher
- Просмотр всех студентов и групп
- Редактирование оценок в журнале
- Просмотр аналитики
- Доступ ко всем вкладкам кроме "Пользователи"

### Роль Student
- Только просмотр своей статистики
- Просмотр своих оценок
- Ограниченный доступ к интерфейсу

## 📊 Функционал

### Вкладка "Главная" (Dashboard)
- KPI карточки: всего студентов, средний балл, успеваемость %, качество %
- Группа риска: студенты с оценками ≤ 4

### Вкладка "Студенты"
- Список всех студентов с фильтрацией по группе
- Средний балл каждого студента
- Детальный просмотр оценок по двойному клику

### Вкладка "Журнал оценок"
- Журнал оценок по группе и предмету
- Редактирование оценок (для admin/teacher)
- Поддержка зачётов (5 = Зачтено, 2 = Не зачтено)

### Вкладка "Аналитика"
- Столбчатая диаграмма среднего балла по группам
- Визуализация через matplotlib

### Вкладка "Пользователи" (только Admin)
- Список всех пользователей системы
- Контекстное меню для повышения ролей

### Вкладка "Настройки"
- Переключение темы (Dark/Light)
- Информация о текущем пользователе
- Кнопка выхода

## 🛠 Технологии

- **Python 3.9+**
- **customtkinter** - современный GUI
- **sqlite3** - встроенная СУБД
- **bcrypt** - хеширование паролей
- **matplotlib** - визуализация данных
- **pandas** - обработка данных (опционально)

## 📝 Примечания

- Все оценки хранятся как целые числа (2-10)
- Зачёты кодируются: 5 = "Зачтено", 2 = "Не зачтено"
- Пароли хранятся в хешированном виде (bcrypt)
- Все действия логируются в базе данных
- Система работает без кэширования для актуальности данных
